## Featured Projects

### Exam-Hall Integrity AI (private: real exam CCTV, demo on request)

Flags malpractice in state recruitment-exam CCTV with no labelled cheating data.

- YOLO11x-pose + ByteTrack on every frame, then per-person rarity scoring (Fisher score over 45 s windows + a stand-up detector), staff and glitch filters, frozen alert lines
- Finds 7 of 14 by-eye-confirmed malpractice moments at ~1 alert per person-hour; scored on a frozen benchmark with a held-out room
- A 90-minute, 40-candidate room becomes ~60 short clips for a human to check
- Qwen3-VL-8B (4-bit) verifies seat detections: 65 / 67 confirmed real, logos and empty desks rejected
- Tested seat-anchored RTMPose-x: 13 to 24 people/frame, but no alert gain; traced why and kept the production path (evidence over novelty)

### Call-Centre Speech Analytics (private: client call audio)

Replaced a paid Gemini API with a self-hosted engine for a recruitment-exam helpdesk.

- Fine-tuned Whisper on Hindi/Hinglish calls: 24.1% WER measured against Gemini transcripts
- Category model trained on ~7,200 Gemini-labelled calls (text classifier + embeddings + nearest calls, tree-model stacker): sub-category agreement 35.3% to 53.2%, category 75.9% to 79.1% on 631 held-out calls
- Low-confidence calls flagged for review, with the next two likely sub-categories
- Shipped into the live portal: wake-on-demand GPU server via AWS Lambda, queued calls drain on wake, one-flag rollback
